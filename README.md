## ⚙️ Run the Portfolio Locally

This portfolio is a static HTML/CSS/JavaScript application with a lightweight Node.js development server.

### 1. Clone

```bash
git clone https://github.com/Umar-fr/Umar-fr.github.io.git
cd Umar-fr.github.io
```

### 2. Start the local server

```bash
node server.js
```

The server runs at:

```text
http://localhost:3000/
```

The included server serves HTML, CSS, JavaScript and image assets and disables browser caching during local development.

### 3. Alternative

Because the portfolio is primarily static, `index.html` can also be served using any static web server.
